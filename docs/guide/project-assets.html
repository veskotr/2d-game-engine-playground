Project and assets

Use a folder project to keep scenes, templates, asset IDs and startup settings together. See project formats and paths.

Project and document commands

Open Recent

Use File → Open Recent to reopen a listed project. Resolve any unsaved edits when prompted.

Close Project

Use File → Close Project while the open project is editable to leave its workspace.

Open Scene…

Use File → Open → Scene… to choose a scene, or open a project scene from Assets. The Scene workspace loads the selected document.

New Entity Template

Use File → New → Entity Template to start a template document in the template workspace. Save it before using it from other scenes.

Open Entity Template…

Use File → Open → Entity Template… or open an existing template asset to edit the template document.

Save As…

Use File → Save As… on the editable document and select a new path. Use the project Assets folder when the new document should be available to that project.

Game window

Open File → Project Settings… and set game title, dimensions, and window mode for the project’s game window, then save the settings before Run Project or export.

Project script trust

Review a project’s Lua scripts before choosing Trust Editor Scripts under Project Editor Scripts in Project Settings. Use Revoke Trust to withdraw it. Project Lua execution in editor workflows depends on the trust setting.

Art Style

Use Project Settings → Art Style to control the default texture filtering for the project. Use per-image settings when a texture needs its own filter.

Sorting Layers

In Project Settings, edit Sorting Layers and assign one to a renderer or tile layer. Use the ordering to control which artwork draws in front.

Collision Layers

In Project Settings, edit Collision Layers and the interaction matrix. Assign a layer to the relevant physics or tile authoring data and test the pair in Play.

Tags

In Project Settings, define tags to reuse across entities. Assign tags in authoring and use them in scripts or event filters.

Assets and templates

Show / Hide Asset Browser

With a project open, use View → Show Asset Browser or Hide Asset Browser to toggle the panel.

Refresh Assets

Use View → Refresh Assets after an external addition or metadata edit to rescan the project.

Texture filter

Select a texture in Assets and use Texture filter in its details to override the project default. Choose Nearest for crisp pixel art or Linear for interpolated sampling. Choose Default to use the project’s Art Style again.

Asset context actions

Right-click the Assets panel for Refresh and Up. Select an asset or folder to see its available operations in asset details. Use project-aware moves and renames to preserve UUID links. See asset identity and operations.

New Folder…

With a project open, click New Folder… in Assets and enter a name to create a folder under the current location.

Recover Deleted…

In Assets, choose Recover Deleted… and select a deleted item from the project recovery list to restore it.

Find References…

Select a registered asset in Assets and use Find References… in its details to see where its UUID is used.

Rename…

Select an asset or folder in Assets and choose Rename…. Confirm the name to rename it through the project index.

Move…

Select an asset or folder in Assets and choose Move…. Select a project destination so asset IDs follow the move.

Delete…

Select an asset or folder in Assets and use Delete…. Review the deletion dialog before confirming.

Reveal in Explorer

Use Reveal in Explorer in the selected asset’s details to locate it on disk.

Open Externally

Select a project file and click Open Externally in asset details to open it in the OS-associated application.

Assign New UUID…

Use Assign New UUID… in asset details to resolve an asset identity conflict. Check references before changing which UUID identifies a file.

Open in IDE

Select a Lua file in Assets and use Open in IDE to open the script with the editor integration.

Open spritesheet…

Select a project texture and choose Open spritesheet… from its asset details or compatible Sprite Renderer controls. Use grid slicing to turn the sheet into reusable regions.

Delete region…

Select an existing region and choose Delete region… in the region controls. Check dependent sprites or tiles before confirming removal.

Entity template overrides

Instantiate a linked template in a scene and edit its exposed component values. Instance overrides persist on the instance; use Apply Changes to Entity Template when you intend to update the reusable source. See linked prefabs.

.sleprefab

From an editable template use File → Export Package… to produce a portable .sleprefab. Use the template import or open workflow to bring it into another workspace. See prefab packages.
