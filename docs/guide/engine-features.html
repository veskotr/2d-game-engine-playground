Engine features

Use these entry points alongside the engine tour and reference index.

Scenes and drawing

Scene switching

Register scene names in the runtime configuration and call Engine.switchScene("Room") from Lua with a registered name. Use the runtime guide and scene lifecycle events to trace the deferred transition.

Chunk activity

Configure a chunked scene and move its gameplay camera across a chunk boundary. The chunk activation controller updates active areas for participating systems. See chunk setup.

Render commands

Add a Sprite Renderer to the First Room entity. In C++, follow RenderSystem as it builds draw commands from scene data and submits them to the renderer. See rendering.

Sprite batching

Place multiple sprites using a shared texture in camera view. The renderer batches compatible sprite commands while preserving ordering requirements. See the Renderer module.

Tile rendering

Open the Tilemap Room and toggle a layer’s visibility before Play. The render system draws visible cells using their atlas regions, layer order, and camera bounds.

Gameplay camera

Create a scene camera and position it to frame the scene. Use First Room Play to check the game framing and the scene schema to configure its fields.

Camera follow

Make the primary camera a child of the player in Hierarchy and set the camera’s local offset. Move the player during Play. CameraSystem reads the camera’s world transform, so the camera follows its parent, including inherited rotation. See scene camera fields.

Prefab expansion

Add a linked template instance with a changed field, then load or play the scene. Prefab expansion resolves the source hierarchy and applies instance overrides. See prefab authoring and merge rules.

Gameplay and services

State machines

Add a State Machine and reference its definition. Configure states and transitions, then call Engine.setStateMachineTrigger(entity, "start") for a trigger named start in the definition. See the scene schema and Lua API for the component and callable functions.

Sprite animation

Assign an Animator with a clip asset, then call Engine.playAnimator(entity, assetPath) during Play. Check the sprite’s frames advance at the configured rate. See the scene authoring schema and Lua API.

Audio playback

Import an audio asset and use Engine.playSound(entity, assetPath, false) from a behaviour to play a one-shot. Check the Lua API for playback and volume controls.

EventBus

In C++, subscribe to a typed event on EventBus, publish it, and dispatch queued events. The events guide documents delivery and subscription lifetime and links the phase examples.

Resource loading

Author project asset references with stable UUIDs and let the project runtime resolve them. For C++ resource loading and cache access, see the Resources module.

XML layout parsing

Register the example HUD as a UI layout. The runtime parses its XML into widgets. Follow First Room’s HUD setup and the XML UI guide.

UI bindings

Bind text or other supported widget fields to runtime values. Watch a value update in the HUD tutorial and use the UI guide for binding syntax.

Game package loading

Follow Export Game, then run the packaged executable from a relocated folder. The loader mounts the package and resolves the startup project and resources. See game package format and validation.
