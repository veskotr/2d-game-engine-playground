Quickstart

Launch the SLE Editor from a Windows checkout and run the NPC Zone demo in the standalone game window.

Install the prerequisites

Use Windows x64 with Visual Studio 2022 and its C++ workload, CMake 3.20 or newer, Python 3, and a 64-bit JDK 21. Use a graphics driver that supports OpenGL 4.3 or later. The first build and Gradle launch need network access to download dependencies.

Open Windows PowerShell at the repository root and install the Python package used for GLAD generation.

python -m pip install jinja2

Build and launch the editor

Set JAVA_HOME to your JDK installation. Build the native editor library and standalone launcher, then start the editor with the Gradle wrapper.

$env:JAVA_HOME = 'C:\path\to\jdk-21'
cmake --preset debug -DSLE_BUILD_EDITOR=ON
cmake --build build/debug --config Debug --target sle_editor_native engine_app --parallel
Push-Location tools/editor
.\gradlew.bat run
Pop-Location

The SLE Editor opens in a desktop window. Close it to return to the PowerShell prompt.

Use the editor launch script

From the repository root, the script finds JDK 21, builds the Debug native library, and launches the editor. To run the demo afterward, build the engine_app target as well.

.\tools\editor\run-editor.ps1
cmake --build build/debug --config Debug --target engine_app

Contributor setup · Editor build instructions

Run the bundled NPC Zone demo

From the repository root, run the standalone launcher with the checked-in configuration.

.\build\debug\engine_app\Debug\engine_app.exe --config engine.json

The SLE Engine App window loads npc_zone_demo. Move with WASD and approach the NPC to trigger the zone behavior. Close the window to exit.

Use --frames 120 for a run that exits automatically, or run the executable with --version to print the engine version.
