Focused validation

Run from the repository root in Windows PowerShell after configuring the Debug tree. Set $case to the test target for your change, then build and run it.

  • Scene codecs and round trip integration_scene_loader_roundtrip_path
  • Runtime transforms and physics integration_runtime_transform_physics_path
  • Scene lifecycle event ordering integration_events_scene_lifecycle_order_path
  • Lua behaviour lifecycle integration_lua_runtime_lifecycle_path
  • UI loading and bindings integration_ui_happy_path
$case = 'integration_scene_loader_roundtrip_path'
cmake --build build/debug --config Debug --target $case
ctest --test-dir build/debug -C Debug -R "^$case$" --output-on-failure

Check the result for skipped cases. Tests exercising a graphics context need a working graphics environment. See the integration target definitions and contributor validation instructions.

Check the guide

From the repository root, scan local guide links and HTML fragment targets, then serve the checkout to check navigation in a browser.

python3 docs/guide/check_links.py
git diff --check
python3 -m http.server 8000

Open http://localhost:8000/docs/guide/. You can also open the guide home directly from disk.
